Vos demandes

Le parcours de contact prépare une demande avec les informations que vous saisissez : nom, coordonnées, message et, le cas échéant, villa et options choisies. Dans cette version, la demande est préparée pour votre messagerie. Elle n’est pas envoyée automatiquement.

Si vous décidez de l’envoyer, Latitude Samui utilise ces informations pour vous répondre et suivre votre demande. Vous pouvez nous contacter à contact@latitudesamui.com pour toute question concernant vos informations.

Préférences sur votre appareil

Votre choix de langue est conservé sur votre navigateur. La sélection des collections peut être conservée pendant votre session pour retrouver votre configuration. Ces préférences ne sont pas transmises par le configurateur.

Services externes

Le chat Odoo est chargé à l’ouverture du site. Sa disponibilité dépend des opérateurs. La carte Google Maps est chargée uniquement lorsque vous choisissez de l’afficher. Ces services peuvent traiter des données techniques selon leurs propres règles.
