# Latitude Samui — version canonique v6

Cette version succède à la v5.

## Modifications

### Navigation
Les sous-menus desktop retrouvent un format compact proche de la version précédente :

- largeur : 330 px ;
- hauteur minimale des entrées : 72 px ;
- titres ramenés à 1,14 rem ;
- espacements intérieurs réduits ;
- sous-titres plus compacts.

Sont conservés :

- les fins séparateurs entre les entrées ;
- le fond ton sur ton au survol ;
- le filet doré animé à gauche ;
- les noms de villas mi-blanc, mi-doré.

### Notre approche
Le bouton « Explorer les finitions », qui renvoyait uniquement vers Villa Sabai, est remplacé par :

- « Découvrir les villas »
- lien vers `index.html#villas`

La section reste ainsi générale et ne privilégie plus arbitrairement une villa.
